# Dataset

Data mentah dan data yang mengandung informasi pengguna tidak di-commit.

- `raw/`: hasil pengumpulan awal.
- `reviewed/`: data yang telah dianonimkan dan dilabeli.
- `splits/train/`: training set.
- `splits/validation/`: validation set.
- `splits/test/`: gold test set.

Gunakan `docs/DATA_COLLECTION_GUIDE.md` dan
`docs/DATASET_GOVERNANCE.md` sebelum menambahkan data.
