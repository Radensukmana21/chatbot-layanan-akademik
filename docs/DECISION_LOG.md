# Decision Log

## 2026-08-02 — Nama repository

Dipilih `chatbot-layanan-akademik` tanpa akhiran versi.

## 2026-08-02 — Lingkungan utama

Laragon/MySQL dan Python virtual environment digunakan sebagai lingkungan utama.
Docker bukan syarat penyelesaian.

## 2026-08-02 — Source lama

Prototipe lama diperlakukan sebagai referensi dan baseline, bukan fondasi yang
langsung disalin seluruhnya.

## 2026-08-02 — Scope awal

Lima use case laporan menjadi layanan utama. Jadwal ujian, kegiatan, dan prestasi
menjadi backlog sampai layanan utama stabil.

## 2026-08-02 — Retraining

Auto-retrain dan auto-promote model dinonaktifkan. Kandidat data harus direview.

## 2026-08-02 — Surat

Chatbot hanya memfasilitasi pengajuan dan status. Approval wajib dilakukan aktor
berwenang setelah SOP sekolah disepakati.
